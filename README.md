# Algorithmic Fairness in AI Lending

## Overview

This independent research project explores algorithmic fairness in AI-assisted lending, focusing on how model performance, applicant data and financial decision systems can raise questions of fairness and accountability.

## Research Objectives

- Explore fairness concerns in AI-assisted lending.
- Compare predictive performance across modelling approaches.
- Examine differences in outcomes across applicant groups.
- Investigate how missing financial data may affect model outcomes.
- Consider governance, transparency and human oversight.

## Methodology

The project uses a synthetic dataset of 500 loan applicants to explore model behaviour and fairness-related questions. It compares conventional and dynamic logistic regression approaches and examines predictive performance, group-level outcomes and the impact of missing data.
